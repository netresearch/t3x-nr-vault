- `AwsVersionedSecretStoreInterface` with `readWithVersion()` and `restoreToVersionIfCurrent()`, implemented by the shipped `AwsSecretsManagerStore`. The AWS adapter takes a write back with the conditional stage move only when its store implements this interface; a store that implements only `AwsSecretStoreInterface`, which is unchanged, keeps the read-then-write rollback. New exception code `1794500015` (`AwsSecretsManagerException::versionMissing()`) for a read whose response names no version id (#567).
