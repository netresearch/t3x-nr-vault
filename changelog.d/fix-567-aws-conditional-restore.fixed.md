- AWS Secrets Manager adapter: when the registry row write fails after an update of an existing secret or after an adoption of an earlier write, the rollback moves `AWSCURRENT` back to the version the write replaced with a conditional `UpdateSecretVersionStage` instead of reading the current version and putting the previous value back. A writer that lands between the write and the rollback now keeps its value; before, the rollback overwrote it. A move that is not confirmed as applied writes nothing and logs a warning naming the secret. Without the new permission `secretsmanager:UpdateSecretVersionStage` the rollback falls back to the old read-then-write and logs a warning. Not covered, unchanged from before: the compensations of a failed audit write (create, update and the valueless completion path), and the rollback of a create, which still deletes a write that lands between the version check and the delete because AWS has no conditional delete (documented in ADR-054) (#567).
