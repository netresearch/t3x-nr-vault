- AWS Secrets Manager adapter: when the registry row write or the audit write fails after an update of an existing secret, the rollback moves `AWSCURRENT` back to the version the update replaced with a conditional `UpdateSecretVersionStage` instead of reading the current version and putting the previous value back. A writer that lands between the update and the rollback now keeps its value; before, the rollback overwrote it. Without the new permission `secretsmanager:UpdateSecretVersionStage` the rollback falls back to the old read-then-write and logs a warning naming the permission. Taking back a create is unchanged: AWS has no conditional delete, so a write that lands between the version check and the delete is still deleted (documented in ADR-054) (#567).
