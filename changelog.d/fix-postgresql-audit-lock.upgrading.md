- The columns `tx_nrvault_secret.value_checksum`, `tx_nrvault_audit_log.hash_before` and `tx_nrvault_audit_log.hash_after` change from `char(64)` to `varchar(64)`. Run the database analyzer (Admin Tools > Maintenance > Analyze Database Structure) or `typo3 extension:setup` after the update. On MySQL/MariaDB and SQLite the stored values do not change. PostgreSQL pads `char` values with spaces, which broke secret reads and audit-chain verification there.
