- `vault:store` refuses `--metadata` keys that the service misread: `groups=…` cleared every group tier of the secret, `frontendAccessible=false` was cast to true and made the secret frontend-readable, and a non-numeric `expiresAt`, `owner` or `scopePid` silently became 0 (no expiry, owner 0, root scope). The record-link keys that orphan cleanup reads (`source`, `table`, `field`, `flexField`, `uid`) are refused too (#524).
