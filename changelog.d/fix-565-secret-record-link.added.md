- `SecretRecordLink` (`Netresearch\NrVault\Domain\Dto`) builds the record link a caller passes as the `metadata` option of `VaultServiceInterface::store()` so that orphan cleanup can find the secret, and holds the list of sources the cleanup considers (`ORPHAN_CLEANUP_SOURCES`) and of those whose link names a FlexForm column (`FLEXFORM_SOURCES`). `OrphanReference` gains an optional `flexForm` constructor parameter; existing calls are unaffected.
- `OrphanReferenceCheckerInterface` (`Netresearch\NrVault\Service`) and `RecordLinkFactoryInterface` (`Netresearch\NrVault\Hook`), with DI aliases, are the seams the orphan cleanup and the vault field hooks use. `OrphanReference::toArray()`/`fromArray()` carry the `flexForm` flag.
- `MigrationResult` gains an optional `failureReasons` constructor parameter and property (the reasons of failed rows; `error` stays for a failure of the whole column), carried by `toArray()`. `FieldValueMigratorInterface` (`Netresearch\NrVault\Service`, `@internal`), with a DI alias, is the seam `vault:migrate-field` and the migration module move values through.
- `IdentifierValidator::isGeneratedIdentifier()` tells a generated (UUID v7) identifier from a friendly name. `SecretRecordLinkWriterInterface` (`Netresearch\NrVault\Service`, `@internal`), implemented by `VaultService` with a DI alias, adds the record link to a secret its caller just created.
- `VaultServiceInterface::store()` accepts a `createOnly` option, which refuses an identifier a secret (enabled or disabled) already holds instead of updating that secret. `FieldMigrationOutcome` (`Netresearch\NrVault\Domain\Dto`, `@internal`) is what `FieldValueMigratorInterface::migrate()` returns.
